# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and patient. People here have different backgrounds, languages and levels of experience.
- Criticize code and ideas, not people.
- No harassment, insults, discriminatory remarks or publishing of someone's private information.

It applies to issues, pull requests, reviews and any other space of the project.

## Reporting

If someone's behavior is a problem, contact the maintainer privately through
[their GitHub profile](https://github.com/HiagoARJ). Reports are kept confidential. The maintainer may remove
comments, close threads or block people who break these rules.
